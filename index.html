无法访问？修改 DNS 即可解决 推荐
多数访问失败可能由 DNS 解析异常导致。可复制下方公共 DNS，并按照设备教程完成设置。
  1. 1
    右下角网络图标 → 右键 → 打开网络和 Internet 设置
  2. 2
    点击 更改适配器选项，找到当前连接的网络，右键 → 属性
  3. 3
    双击 Internet 协议版本 4 (TCP/IPv4)
  4. 4
    选择 使用下面的 DNS 服务器地址，首选填 8.8.8.8，备用填 8.8.4.4
  5. 5
    点击 确定 保存，刷新页面即可
  1. 1
    点击左上角苹果菜单 → 系统偏好设置（或系统设置）→ 网络
  2. 2
    左侧选中当前连接，点击 高级 → 切换到 DNS 标签页
  3. 3
    点击左下角 +，依次添加 8.8.8.8 和 1.1.1.1
  4. 4
    点击 好 → 应用 保存，即刻生效
  1. 1
    打开 设置 → Wi-Fi，点击当前连接网络右侧的 ⓘ
  2. 2
    下滑找到 配置 DNS，点击改为 手动
  3. 3
    删除原有 DNS，点 添加服务器，输入 8.8.8.8，再次添加 1.1.1.1
  4. 4
    点击右上角 存储，返回即可

💡 仅对当前 Wi-Fi 生效。切换网络后需重新设置，或在路由器统一修改。

  1. 1
    打开 设置 → 网络与互联网（或 WLAN）→ 长按当前 Wi-Fi → 修改网络
  2. 2
    展开 高级选项，将 IP 设置改为 静态
  3. 3
    在 DNS 1 填入 8.8.8.8，DNS 2 填入 1.1.1.1
  4. 4
    点击 保存，重新连接 Wi-Fi 即可

💡 也可在设置中搜索"私人 DNS"，填入 dns.google，对所有网络生效。

  1. 1
    浏览器输入路由器管理地址，常见为 192.168.1.1 或 192.168.0.1，登录管理后台
  2. 2
    找到 WAN 设置 或 宽带设置 → DNS 设置
  3. 3
    首选 DNS 填 8.8.8.8，备用 DNS 填 1.1.1.1
  4. 4
    保存设置，路由器自动重启后，局域网内所有设备立即生效

💡 路由器修改一次，家中所有设备同时受益，推荐优先选择此方案。
